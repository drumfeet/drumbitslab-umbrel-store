## Security settings

The catalog changes only the Collector image references and release metadata.
The web process remains non-root with a read-only root filesystem, all Linux
capabilities dropped and `no-new-privileges`. The one-shot data initializer keeps
its existing narrow ownership-repair command and capabilities. Persistent data
paths, service dependencies, ports, authentication configuration and the existing
cloudflared image are unchanged. The tunnel still runs as UID/GID 1000 with a
read-only token mount, dropped capabilities and `no-new-privileges`.

## Before a separately approved installation

Take a private stopped-app checkpoint of Collector's data and tunnel directories.
Include `tradingview-cooldown.json` when present, the latest credentials, schedules,
pending work and publication records. Keep backups outside this public repository.
Older installations that have not completed the private runtime configuration
migration must complete it first.

The published candidate passed all nine synthetic recovery phases from the exact
0.5.13 image, including upgrade, credential refresh, recreation, image-only rollback,
cooldown expiry and cold restore. These checks used disposable data and no provider
network access. They do not replace a private backup of the installed app.

For rollback, retain the previous catalog package and image:
`ghcr.io/drumfeet/atlas-almanac-collector:0.5.13@sha256:4c351370dff4b3c032615f974279bd784e6c5fa6fe2fedefe9f30af88bc4e1be`.
Preserve current credentials and cooldown state when reverting the image. Restoring
an older full snapshot can discard newer work or credentials. Version 0.5.12 predates
the cooldown fix and is not the preferred rollback target.

Preparing this catalog PR does not merge it or update an installed app. Installation
requires separate approval and a Collector-only stop/start. Bitcoin Knots, Electrs
and wallet connections do not need to be restarted for this package update.
