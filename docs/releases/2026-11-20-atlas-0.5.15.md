# Atlas Almanac Collector 0.5.15

Collector publishes daily PSE quotes for the 283 configured listings. It uses
Phisix API 3, the API 2 mirror, and PSEye for individual fallback quotes. MGENR
is the current ticker for the former SPNEC listing.

This release retires scheduled stock candle collection and the TradingView
company refresh. Existing archives, checkpoints and saved publication receipts
are preserved. Bond collection, PSEye metrics, dividends and daily Alerts
continue on their existing schedules.
