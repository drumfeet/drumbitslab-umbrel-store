## Preserve the current configuration

An existing 0.5.3 installation needs no settings or schema migration. Keep its private watchlist, including owner edits and any configured path override, in place. Do not export legacy defaults over it or create a replacement empty file. Preserve its ownership and permissions, credentials, enabled schedules, publication receipts, checkpoints, histories and archive/reservation ledgers.

Existing installations older than 0.5.3 must first complete the [private runtime configuration migration](../private-runtime-config-migration.md). A fresh installation can start with an empty watchlist. Do not use a fresh-install configuration to replace an existing owner's data.

Both `data_init` and `web` use the same verified 0.5.4 image. The app ID, ports, data mount, origin, tunnel image and token-file mount, dependencies, startup order and container security options stay unchanged. Pricewatch and Visual Status Checker are outside this release.

## Later authorized installation

1. Record the current immutable image pin and enabled schedules privately. Drain active work and reconcile uncertain publications before stopping Atlas through Umbrel.
2. Take a consistent private backup of the complete app-data and tunnel directories. Preserve numeric ownership, modes, symlinks, private configuration, rotating credentials and retained state. Verify an offline restore to an isolated copy; keep the original backup separately.
3. Rehearse the candidate against that copy with network access, scheduling and notification delivery disabled. Compare the watchlist, settings, credentials and saved state without writing production data.
4. After catalog validation, review, merge and separate installation authorization, apply the update through Umbrel's supported interface. Do not edit installed Compose files manually. Verify the installed digest, health, private configuration and retained settings. Restore only settings temporarily paused for maintenance to their recorded prior values; do not enable additional schedules or send live test notifications.
