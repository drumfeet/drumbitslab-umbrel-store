# Atlas Almanac Collector 0.5.17

Collector can publish its two current snapshots through the existing Atlas Alerts Worker. Deploy the Worker and configure its publication secret first. Install the matching secret as a private file in the Collector data volume. The existing R2 snapshots must already be seeded. Verify the published bytes at all six public data URLs.
